# Neon Swim 🐟

A one-file neon arcade game. Guide a glowing fish through an endless tunnel — **hold to rise, let go to fall**. Don't touch the glowing walls!

## How to play

- **Hold** (press and hold the screen / `Space`) — the fish rises
- **Let go** — the fish falls
- Dodge the glowing tunnel walls, grab golden orbs for points
- Chain orb pickups for **streak bonuses**

## Power-ups

| Power-up | Effect |
|----------|--------|
| 🛡 Shield | Survives one wall hit |
| ⏳ Slow-mo | Slows the tunnel for 6s |
| 🧲 Magnet | Attracts orbs for 8s |

## Features

- Smooth hold-to-rise / release-to-fall physics
- Glowing neon tunnel with corals, bubbles and plankton
- Streak combo scoring with rising pitch sound effects
- Shield / Slow-mo / Magnet power-ups
- Pause, mute, and persistent best score (`localStorage`)
- Mobile-friendly portrait layout, keyboard support (`Space`, `P`, `M`)

## Run it

Just open `index.html` in a browser — no build step, no dependencies.

## Deploy

Static site. Works on any static host (Vercel, Netlify, GitHub Pages).
